# Third-party attribution

MoTRUST retains its MIT license. Dependencies, comparison methods, gene
annotations and datasets retain their own licenses and usage terms.

The common integration metrics in `motrust.benchmark.metrics` follow the
Palette paper equations and public reproduction code; their source
attribution is retained. The benchmark protocol records the reference
revision. Palette, MIDAS, scMoMaT, StabMap and MoNAE are external comparison
methods, and their complete source repositories are not redistributed here.

Python dependencies include NumPy, SciPy, pandas, scikit-learn, PyTorch and
AnnData. R conversion helpers use jsonlite and Matrix. These dependencies
are installed separately with their own notices.

Original study accessions and the processed input release are listed in
[datasets.md](datasets.md). Referencing a processed release identifies the
inputs used; it does not require running another integration method first.
